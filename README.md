# 《元衡论》 V3.0

## 简介
本仓库为《元衡论》第三阶段文稿归档。
V1.0、V2.0 构建底层理论模型，偏于理与思辨；
V3.0 重心落在**行**，以经典义理为依托，记录修行实践、习气转化、观照实证、普贤行持，探讨证悟之路。

> 定位：解读、转译传统解脱道的实践体系，探究如何修、如何破执、如何证悟。
> 后续V4.0 将另起篇章，转向生命本然的大慈悲底色立论，不再限于经典注解。

## 文件说明
本仓库收录一系列 Markdown 文稿：
- 实修实证基础、安那般那念（出入息念）
- 情绪觉察、心念势差、习气转化（嗔恨、慢心等）
- 对话摘录、思辨推演记录

## 重要声明
全部内容仅为个人思考与思辨记录，非教法，非定论。
仅供有缘人参考辨析，不构成修行指导。
接纳者取用，不合者放下，不强求认同。
