# 元衡论 V3\.0 归档片段

## 主题：苦、势差、本体自扰动与觉照的辨析

### 一、从底层势差结构拆解“苦”

剥离主观感受、情绪、价值评判，仅从底层逻辑推演。本体是圆满动态平衡的基底，本身无缺损、无分别。一切万象，皆是本体内部自发涌现的势差。势差天然具备趋向弥合、回归平衡的特质，这是客观规律，本无苦、乐标签。

势差本身，只是局部系统不平衡所产生的张力，不附带难受的感受。苦的产生，来自第六识的控制习气与势差自然回归趋势之间的对抗张力。

第六识本能想要抓取、留住喜爱的势差，排斥、消灭不喜的势差。当意识强行干预、抗拒势差自然流转，便叠加额外拉扯，这就是我们感知到的苦。

需要区分两层：

1. 世间相对之乐：依托势差对比而生。是从不平衡走向平衡的落差带来的短暂安稳，必须依靠苦作为参照，有局限性，会随势差变化消失。

2. 本体层面的极乐：不是消灭所有势差。安住本体圆满基底，同时清晰观照一切涌现的势差起伏。本体为体，势差显现为用；体不动，用不停。能同时照见体与用，自在不被势差裹挟，才是极乐。

若仅有单纯平衡态，没有势差显现，便不存在观照，无法显发极乐。

### 二、个体与环境一体共生，二元对立的误区

生命体和周遭环境，并非舞台与演员的关系，而是同一套势差场一体共生涌现。人体本身就是和微生物、尘土、大气、压强、引力耦合在一起的动态共同体。肠道、口腔内菌群并非外来异物，是构成生命系统的一部分。

细菌、灰尘本无“干净/肮脏、有益/有害”的固有属性。好坏，只是第六识基于肉身局部稳定建立的价值取舍。只有菌群失衡、势差剧烈偏移，才会引发肉身应激反应。

洁癖是典型例子：追求绝对无菌、一尘不染的环境，本质是意识执着一个理想化、不存在的纯净状态，制造自我与环境的二元割裂。免疫系统需要和环境微生物持续交互，长期隔绝正常环境刺激，会造成机能弱化。适度清洁是维持局部势差稳定的手段，而非追逐绝对纯净。

个体生命，只是局部势差临时形成的稳定闭环幻象。我们的感知、思维、价值判断，全部是这套闭环的产物。换一组势差条件，涌现的生命形态、感知方式、评判标准都会完全不同。可以类比多元宇宙的猜想：不同本体自性，涌现出完全不一样的世界与生命。此猜想仅作推演，不做定论。

### 三、主体、认知、觉照的边界辨析

觉照、第六识的分别认知，同属二元认知活动。只要存在能观者、被观之物，能所成对出现，就是认知，属于“用”。

- 第六识：见境→分别判断→抓取或对抗。

- 带有能所的觉照：见境，单纯照见，不附加取舍评判，结构和第六识同构，只是不生抓取习气。

这里存在两条悬置的推演路径，不下最终定论：

路径一：觉照属于局部闭环内部。觉知、思维全部是闭环内生的功能，闭环势差构型消散，觉照功能随之熄灭。

路径二：觉性属于更高层本体。局部肉身心念闭环只是载体，如同透镜，承接显化觉性成为觉照。闭环会生灭，但觉性本身不随闭环消散。

认知是二元势差的产物，依靠自身思辨无法消融能所二元。头脑可以在观念上看懂幻象，但只能更新认知内容，能所的对立势差依旧存在。能所消融，不是逻辑推理的结果，是二元势差自然平息之后显现的状态。

### 四、主观觉照是过渡之门，本体无主观意志

本体本身不存在主观的“我”，没有念头，不会刻意去观照、抹平势差。一切显现、照见、势差生灭，都是依本体之性，客观自然发生。

修行阶段主动发起的觉照，是调用第六识形成的用功，属于局部闭环内的一股势差。它是一扇门、一个路标，是过渡阶段的接触点。它的作用，是停止新增抓取对抗的势差，而不是直接制造本体的明性。

1. 凡夫阶段：第六识持续分别取舍，不断叠加对抗的势差，遮蔽自性本有的明。

2. 观照过渡阶段：启用主观觉照，仍有能所二元，但不再新增执念拉扯。

3. 能所消融之后：主观觉照这股用功的势差完成使命，自然息灭。不再有“我要观照”的主动动作，没有观者，没有所观之物，自性照见自然显露。

不可执着守住觉察的“我”，一旦执着觉照本身，又会产生新的抓取，形成新的遮蔽。整个过程不是“小我”努力获得本体，而是停止新增对抗势差，遮蔽淡化，自性本有的照见自然显现。

### 五、本体自扰动，体不变而用不停

能所消融之后，势差依旧持续涌现，只是不再升起小我抓取、能所对立。万象照常显现，但是没有一个“我”站在对面做取舍评判。

这里要注意具象比喻的局限：以大山作比方，容易让人误以为扰动来自外部。实相上，一切现象、扰动、生灭变化，全部是本体内部自起自灭，不存在外部干扰。所有势差显现，都是本体自身性德的起用。本体基底不会被内部势差起伏磨损、改变。

本体是自带自扰动的拓扑体系（三维河图洛书模型）。如果本体是绝对静止，就无法涌现任何万象。扰动本身极其细微，我们证悟时体会到的是扰动之性，未必直接体会扰动的全部规则。势差的涌现，是本体永恒自带的自扰动，无始无终。

### 小结

世间一切苦，根源不在外境，而在意识对势差的抓取对抗；个体与环境同源共生，独立的“我”只是局部势差的临时闭环幻象。主观觉照是过渡工具，功用是止息新增执念；本体无主观意志，一切生灭是自扰动的客观显现。安住本体，万象势差照常流转，不起能所对立，有应对之用，无小我之执。本体基底恒常，自扰动无始无终，万象皆是本体的起用。
